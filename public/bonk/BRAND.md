# BONK Brand Kit - reference for The Card Wall x BONK tournaments

Source: https://brand.bonkcoin.com/ (full kit mirrored in this folder).
Scope: used ONLY on /tournaments for the sponsorship. Rest of the site
keeps the Card Wall palette.

Asset layout:
- `public/bonk/web-img/`  - optimized PNGs the app actually serves.
- `public/bonk/fonts/web/`- Poppins + Space Mono TTFs the page loads.
- `brand-kit/bonk-full/`  - complete raw kit, kept LOCAL ONLY (gitignored,
  not committed). Re-fetch from https://brand.bonkcoin.com/ if needed.
  Scraper output that produced it lives in this doc's "Key assets" list.

## Naming (hard rule)
- Always written `BONK` in all caps. Never "Bonk", never "bonk".

## Color palette
Primary (brand):
- White   `#FFFFFF`
- Yellow  `#FFE208`
- Orange  `#FC8E03`
- Red     `#FF0000`  (use SPARINGLY - reserved for "!!!" and typography accents)

UI (digital applications - prefer these on screen):
- UI Yellow `#FDC202`
- UI Orange `#FF5C01`

Mascot:
- Nude `#F7BD9F`  (ONLY for BONK Dog's ears - do not use elsewhere)

Secondary / accents:
- Pink   `#FA7EF3`
- Purple `#7933BC`

Partnership / dark-mode (night, depth, lighting):
- Midnight  `#17001C`
- Grey      `#2B3649`
- Black     `#000000`
- Light Grey`#EEEEEE`

Backgrounds: BONK likes gradient backgrounds to "bring BONK to life".

## Typography
- Herborn  - LOGO ONLY (all-caps, limited glyph). Do not use for body.
- Poppins  - primary typeface (geometric, many weights). Mirrored as zip.
- Helvetica- fallback when brand fonts unavailable.
- Space Mono - small details: data, filters, stats, timers. Mirrored as zip.

## Mascot - BONK Dog
3D-rendered orange shiba, cream snout/belly, nude ears. "A winner!!!" -
noble, never gives up, light in the dark. Kids can hug him. Poses available:
Head, One (peace/index), Peace, Point x2, ThumbsUp, Wave. Use tastefully,
let it flow with the layout; don't smatter images.

## Partnership lockup
- Layout: `[Partner logo]  x  X  x  [BONK]` where x = BONK width / 3.
- "powered by BONK" lockup also available (logos/powered_by_bonk.png).

## Do NOT
- Don't recolor the logo / dog (do_not_colors).
- Don't add effects/shadows/glows to the logo (do_not_effects).
- Don't stretch or distort (do_not_stretch).
- Don't recreate the logo (do_not_recreate).
- Don't overuse red.
